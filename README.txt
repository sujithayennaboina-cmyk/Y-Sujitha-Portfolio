# Y. Sujitha — Animated Portfolio

## Run
Just open `index.html` in Chrome/Edge/Firefox.

## Included
- Responsive dark premium design
- Scroll reveal animations
- Animated neon rings and ambient glow
- Mouse-follow glow
- Mobile navigation
- Active section navigation
- Project detail modal
- Education, projects, internship and skills sections
- Profile image included in `assets/sujitha-profile.png`

## Customize
1. Change email `sujitha@example.com` in `index.html`.
2. Replace social `#` links.
3. Add `resume.pdf` and connect the Download Resume button.
4. Update project descriptions/technology tags as needed.
